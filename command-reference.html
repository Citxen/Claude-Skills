Command Reference

Microsoft Intune / government worked example. Claude Code, repo: Claude-Skills.

The full run, in order

/discovery-creator Microsoft Intune government
/hld-creator Microsoft Intune government --skeleton
/hld-creator Microsoft Intune government --base microsoft-intune-government-hld-skeleton.md
/code-review high

Discovery

/discovery-creator Microsoft Intune government
/discovery-creator Microsoft Intune government --refresh microsoft-intune-government-discovery-pack.xlsx

Writes to .claude/skills/hld-creator/artifacts/discovery/. Refresh re-researches and updates sources without clearing answers already filled in.

HLD

/hld-creator Microsoft Intune government --skeleton
/hld-creator Microsoft Intune government --base microsoft-intune-government-hld-skeleton.md
/hld-creator Microsoft Intune government
/hld-creator Microsoft Intune government --base 2024-endpoint-hld.docx

Context goes on the next line, never appended to the arguments — the last word is read as the sector:

/hld-creator Microsoft Intune government --base microsoft-intune-government-hld-skeleton.md
UK central government, OFFICIAL and OFFICIAL-SENSITIVE, single tenant, 6 agencies,
BYOD app-protection only.

Caveman

/caveman
/caveman lite
/caveman ultra
/caveman wenyan-full

Set once, then keep working. Changes how replies are written, not what the skills produce.

/caveman ultra
/discovery-creator Microsoft Intune government

Code review

/code-review
/code-review high
/code-review max --fix
/code-review .claude/skills/discovery-creator
/code-review ultra
/code-review 7 --comment
/simplify
